# Serhii Diediukh — Photography

Мінімалістичне адаптивне портфоліо за наданим референсом. HTML, CSS і JavaScript; без залежностей для роботи сайту.

## Запуск

```sh
npm run dev
```

Відкрити http://127.0.0.1:3000. Достатньо Node.js 22+; додаткові пакети не потрібні. `npm run build` готує сайт у `dist/`.

## Редагування

- `index.html` — ім’я, підзаголовок, email та посилання.
- `styles.css` — типографіка, композиція та мобільний вигляд.
- `app.js` — категорії, фотографії, підписи та галерея.
- `public/assets/` — локальні зображення і шрифти.

Галерея підтримує мініатюри, кнопки, стрілки клавіатури, свайпи та збільшення фото. Escape закриває перегляд. Посилання на фотоплатформи зараз ведуть на головні сторінки — замініть їх адресами власних профілів. Email відтворено з макета.

Головне фото відображено з наданого знімка екрана за допомогою CSS. Інші фото — демонстраційні зображення Unsplash, не авторські роботи власника портфоліо. Для фінального портфоліо замініть їх власними фотографіями. Шрифти Barlow Condensed і Cormorant Garamond завантажуються локально.

## Перевірка

`npm test` перевіряє галерею у встановленому Google Chrome, зокрема мобільний вигляд, клавіатуру, мініатюри та збільшення. Для іншої ОС передайте шлях до Chrome через `CHROME_PATH`.
